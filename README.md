# JULEDemo - 多功能项目

## 项目组成

本项目包含两部分：
1. **控制台应用程序** - 查询字符串解析器（QueryStringParser）
2. **简单博客推荐页面** - 展示博主"冰茶"的内容

## 查询字符串解析器 (C# 控制台程序)

### 功能描述

这是一个 C# 控制台应用程序，用于演示如何解析 URL 查询字符串，并将其转换为键值对字典。程序支持多种情况下的查询字符串解析：
- 基本查询字符串
- 带有前导 '?' 的查询字符串
- 包含 URL 编码字符的查询字符串
- 包含空值和无值参数的查询字符串
- 特殊字符处理

### 如何运行控制台应用程序

#### 方法1：使用 Visual Studio

1. 打开 Visual Studio
2. 打开项目中的 `JULEDemo.sln` 解决方案文件
3. 按 F5 或点击"开始"按钮运行程序

#### 方法2：使用命令行

1. 打开命令提示符或终端
2. 导航到项目目录
3. 使用 .NET CLI 运行程序：
   ```
   dotnet run
   ```

### 技术栈
- C# 12.0
- .NET 8.0

## 简单博客推荐页面

### 页面描述

这是一个简单的前端网页，用于展示对特定博主的推荐。它使用了基础的 HTML, CSS, 和 JavaScript。

当前页面主要特色：
*   推荐 **冰茶** 的 CSDN 博客。
*   展示该博主的近期精选文章列表，包含标题和直接链接。

### 如何运行网页

#### 在本地查看

1.  克隆本仓库到您的本地计算机。
2.  直接在浏览器中打开 `index.html` 文件即可查看。
