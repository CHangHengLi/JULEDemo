# 前端网页 Demo

## 项目描述

这是一个基础的前端网页 Demo，包含了 HTML, CSS, 和 JavaScript 文件。它旨在演示一个简单的网页结构，包含一个角色展示区域和一些基本样式。

## 技术栈

*   HTML5
*   CSS3
*   JavaScript (ES6+)

## 如何运行
